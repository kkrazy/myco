# 平台接入 + 模型切换大更新

本次更新带来了多个平台接入方式和更灵活的模型切换能力，以下是本次上新的功能速览。

## 🔄 `/model` — 模型网关切换

- 直接输入 `/model` 打开选择器，查看并切换当前可用的模型网关。
- `/model gw:<名称>` 激活指定的网关配置；`/model gw:default` 恢复系统默认。
- 每个会话可以独立选择不同的网关，互不影响。

## 📋 `/fr @myco` — 快速功能请求

- 在聊天里直接用 `/fr @myco <描述>` 提交功能请求，请求会记录到 Plan 面板。
- 支持投票、评论，重要需求会被排进任务队列。

## 🤖 `/run-n2` — N2 模式任务派发

- 用 `/run-n2 <任务描述>` 以 N2 模式派发任务，主会话模式不受影响。
- 适合并行推进独立子任务，任务状态可在 Plan 面板实时查看。

## 🧠 RLM 会话支持

- 新增 RLM（Reasoning-Language Model，推理语言模型）会话类型，可通过 spawn 面板创建。
- **更节约上下文**：上下文管理从"窗口 + 压缩"升级为 **REPL + 变量**——信息存放在运行环境的内存里，模型用变量按名读写，对话窗口中只保留变量引用而非全文，同样的上下文预算能承载远多于传统窗口压缩方案的工作量。
- **Continual Harness**：框架从"设计时固定"升级为**运行时可 CRUD**——提示词、子代理、任务编排（Factory DAG）都可以在运行中动态增删改查，无需重启会话。
- RLM 会话走独立的提示词与运行链路，支持通过编程方式派生子代理并行推进任务。

## 🔗 delm / codehub / 自带 Claude Code 接入

- 现在支持 **delm**、**codehub** 平台账号接入。
- 也支持使用你**自己的 Claude Code**（本地 CLI）作为执行引擎。
- 在 Config 面板中配置对应网关即可启用。
